How Gesture Flow Operates

A deterministic, 4-stage pipeline running strictly on your local device for maximum safety and privacy.

01

Front Camera

Captures RGB video frames at 30–60 FPS with non-blocking single-frame buffers.

02

MediaPipe Tracking

Extracts 21 3D hand landmarks with One-Euro smoothing and jitter suppression.

03

Geometric Classifier

Classifies finger flexion, pinch distances, and velocity vectors through a state machine.

04

OS Action Dispatch

Executes safe Android Accessibility / Win32 actions via an explicit security whitelist.

Core Capabilities

Designed for Speed, Safety & Precision

Low-Latency CV

Optimized MediaPipe Lite inference delivering responsive gesture tracking with sub-millisecond drawing.

Safe Action Whitelist

Zero arbitrary shell execution. Dispatches only authorized UI actions like tap, scroll, and volume.

100% Offline-First

Gesture control runs fully without internet using local SQLite storage and offline sync queues.

Android Accessibility

Emergency Safety Stop

Strict Privacy by Design

Gesture Flow performs 100% of computer vision and video frame processing locally on-device. Raw camera streams and photos are never uploaded to the cloud or stored on servers. The cloud database stores only user preference settings, calibration thresholds, and non-sensitive interaction counts.

1. Mathematical Formulation of Landmark Smoothing

To eliminate high-frequency hand tremors while preserving low-latency trajectory responsiveness, the pipeline implements an adaptive One-Euro filter:

α = 1.0 / (1.0 + τ / Δt), where τ = 1.0 / (2π · f_c)
f_c = f_c\_min + β · |dx/dt|
